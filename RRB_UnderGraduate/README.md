# RRB NTPC Undergraduate

Same layout as `../RRB_Graduate`. The CBT subject matter (Maths, Reasoning, GA) is shared with Graduate, and these files build on it:

| File | What is Undergraduate-specific |
|---|---|
| `plan.js` | Adds a daily 30-minute **Typing** track to the 91-day plan |
| `syllabus.js` | Class 12 level note, plus a Typing skill test block |
| `notes.js` | Railway commercial basics, Accounts and office basics, Typing sheet |
| `tricks.js` | 8 typing tricks (speed maths, technique, Inscript, test day) |
| `quiz.js` | 20 questions on typing, railway commercial terms and accounts |
| `index.js` | Pattern with the typing test, plus station goals that include typing |
| `resources.js` | Searches and books for Undergraduate posts and typing practice |
