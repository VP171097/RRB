# Mission 90 (NTPC Prep)

A study tool for the RRB NTPC (graduate) CBT, built with React and Vite. No server and no account: progress is saved in your browser.

**What is inside**

| Tab | What it does |
|---|---|
| Mission | The game: 13 stations (the 13 weeks), a boss at each, daily quests, fuel gauge. Win by scoring 90+ |
| Tricks | 83 maths and reasoning shortcuts grouped by syllabus topic, with try-it examples |
| Practice / Focus / Rewards | Quiz, Speed Maths, flashcards, focus timer, XP, ranks and badges |
| Today / Days | 91-day plan with a checkbox for every task, by day and week |
| Topics | Per-topic tracker: Learn, Practice, Rev 1, Rev 2, Rev 3 |
| Syllabus | Detailed syllabus (every heading in the notification, 52 topic groups) with priority, indicative weight, tick-off, practice and video links |
| Exam | Stage 1 and 2 pattern, marking, qualifying marks, time split, score calculator |
| PYQs | Where to find previous-year papers, a 12-paper attempt log, topic-wise PYQ links |
| Library | PDFs stored in `public/pdfs/`, with Open and Download buttons |
| Resources | Official sites, free study sites, books, video courses |
| Mocks / Errors | Mock score log and trend, error log with 7-day revisit reminders |
| Notes | Formula sheet, reasoning methods, Railways GK, polity, science, static GK, current-affairs checklist |
| Study log | Timer and manual minutes, weekly chart |
| Settings | Start date, daily target, theme, backup and restore |

## Run locally

Needs Node 20 or newer.

    cd ntpc-prep
    npm install
    npm run dev          # http://localhost:5173

To serve the production build locally instead:

    npm run build
    npm run preview

## Put it on GitHub Pages

1. Merge this folder into `main`.
2. In the repository: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. The workflow in `.github/workflows/pages.yml` builds and publishes on every push to `main` that touches `ntpc-prep/`.
4. The site appears at `https://<your-username>.github.io/<repo-name>/`.

Progress lives in each browser's local storage, so the Pages site and `localhost` keep separate copies. Use **Settings → Export backup** and **Import backup** to move progress between them.

## PDF library

PDFs live in `public/pdfs/` and are committed to git:

    public/pdfs/syllabus/   notification, syllabus
    public/pdfs/pyq/        previous-year papers
    public/pdfs/notes/      your notes
    public/pdfs/books/      reference material
    public/pdfs/other/

Add a file by dropping it in a folder, or let the script fetch it:

    npm run fetch-pdf -- "https://example.com/paper.pdf" pyq/ntpc-2025-shift1.pdf
    git add public/pdfs && git commit -m "Add paper" && git push

`public/pdfs/manifest.json` is regenerated by `npm run dev` and `npm run build`. The Library tab reads it, so a pushed PDF appears after the next deploy. Some sites block scripted downloads; in that case save the file from your browser and drop it in the folder.

Only keep material you have the right to keep. Large files make the repository heavy; GitHub warns above 50 MB per file.

## Editing the plan

- `src/data/plan.js`: the 91-day schedule and topic lists
- `src/data/syllabus.js`: syllabus sections and sub-topics
- `src/data/notes.js`: formula sheets and GK notes
- `src/data/resources.js`: links and PYQ searches

Links to papers are searches on purpose, because coaching sites move files often. Replace any of them with a direct link you trust.
