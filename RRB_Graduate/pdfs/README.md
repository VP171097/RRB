# PDF library: NTPC Graduate

Put PDFs in these folders and commit them. The site lists them under **Learn → Library** when NTPC Graduate is selected.

| Folder | Use for |
|---|---|
| `syllabus/` | Official notification, syllabus, exam pattern |
| `pyq/` | Previous-year question papers and answer keys |
| `notes/` | Your own notes, formula sheets, current-affairs compilations |
| `books/` | Book chapters and reference material you are allowed to keep |
| `other/` | Anything else |

Add a file by dropping it in a folder, or from `app/` run:

    npm run fetch-pdf -- "<direct-pdf-url>" graduate/pyq/ntpc-2025-shift1.pdf

Only keep material you have the right to keep. Official RRB notices and papers are fine.
