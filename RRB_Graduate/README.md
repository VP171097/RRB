# RRB NTPC Graduate

Everything specific to this exam. The website in `../app` reads these files.

| File | Content |
|---|---|
| `index.js` | Exam name, section sizes and timings, pattern tables, links the rest together |
| `plan.js` | 91-day study plan: the topic list per subject and the timed-practice weeks |
| `syllabus.js` | Detailed syllabus with priority and indicative weight |
| `notes.js` | Formula sheets and GK notes (also become flashcard decks) |
| `tricks.js` | Maths and reasoning shortcuts with worked examples |
| `quiz.js` | Quiz question bank |
| `resources.js` | Official links, books, videos and previous-year paper searches |
| `pdfs/` | Your PDFs (syllabus, papers, notes, books) |

Edit these files and the site updates on the next build.
